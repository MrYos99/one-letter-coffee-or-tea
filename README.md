# One Letter: Coffee or Tea

A program that writes exactly one letter to `/output/entry.txt`: `A` for
coffee. Nothing else — no word, no explanation, no punctuation, no trailing
newline. The gate requires UTF-8 text of exactly 1 character, and the
program self-checks that the file on disk is exactly one letter before
exiting 0. Node 22 standard library only — no network, no external packages.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
